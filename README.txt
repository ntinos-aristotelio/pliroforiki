Πτυχίο Πληροφορικής - Demo
==========================

Τι περιέχει:
- index.html: η εφαρμογή
- styles.css: εμφάνιση
- app.js: λειτουργικότητα
- data/questions.js: οι 432 ερωτήσεις EXPRESS A/B
- assets/*.svg: πρωτότυπες εικόνες-οδηγοί βήμα-βήμα

Πώς ανοίγει:
1. Αποσυμπιέζεις τον φάκελο.
2. Ανοίγεις το index.html σε Chrome/Edge/Firefox.

Πώς ανεβαίνει στο GitHub Pages:
1. Ανεβάζεις όλα τα αρχεία σε repository.
2. Settings -> Pages -> Deploy from branch.
3. Επιλέγεις main branch και /root.

Σημείωση:
Τα SVG είναι πρωτότυπα εκπαιδευτικά mockups, όχι αντιγραφή των PDF.
