# Word Practice - Πτυχίο Πληροφορικής

Πρώτη καθαρή δοκιμαστική έκδοση μόνο για την ενότητα Word.

## Τι περιέχει

- 72 ερωτήσεις Word από τα EXPRESS A/B.
- Απλό μενού τριών επιλογών: Μαθαίνω, Εξάσκηση, Μικρό τεστ.
- Οπτικούς οδηγούς βήμα-βήμα σε δικά μας SVG γραφικά.
- Αποθήκευση ερωτήσεων για επανάληψη στον browser του μαθητή.

## Ανέβασμα σε GitHub Pages

Ανέβασε όλα τα περιεχόμενα του φακέλου στο repository:

```text
index.html
styles.css
app.js
data/
assets/
README.md
```

Μετά πήγαινε Settings → Pages → Deploy from a branch → main / root.

## Σημαντικό

Αυτή είναι δοκιμή ύφους και ροής. Οι εικόνες είναι καθαρές επεξηγηματικές μακέτες, όχι αντιγραφή των PDF. Στην επόμενη φάση μπορούν να γίνουν πιο κοντά στο πραγματικό Word, με επιλεγμένα screenshots ανά εντολή.
