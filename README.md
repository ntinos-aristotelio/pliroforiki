# Word demo v2

Δοκιμαστική web εφαρμογή μόνο για Microsoft Word.

## Τι άλλαξε
- Πολύ απλό μενού: Μαθαίνω, Εξάσκηση, Μικρό τεστ.
- Οι εικόνες δεν είναι τυχαία SVG. Είναι οδηγοί με πραγματικά αποσπάσματα από το Word PDF που δόθηκε ως υλικό αναφοράς.
- Δεν μπαίνει εικόνα αν δεν έχει σχέση με την ερώτηση.

## GitHub Pages
Ανεβάζεις τα περιεχόμενα αυτού του φακέλου στο repository και ενεργοποιείς Pages από `main / root`.
