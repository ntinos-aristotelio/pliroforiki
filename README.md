# Μαθαίνω Word - διαδραστική εφαρμογή

Πρώτη λειτουργική έκδοση για προετοιμασία πληροφορικής τύπου ECDL / ICDL με έμφαση στο Word.

## Τι περιλαμβάνει

- Αρχική οθόνη
- Ενότητα «Μαθαίνω» με μικρά μαθήματα
- Ενότητα «Εξάσκηση» ανά κατηγορία
- Διαδραστικές ασκήσεις όπου ο μαθητής πατάει πάνω στην εικόνα
- Ερωτήσεις πολλαπλής επιλογής με εξήγηση
- Άσκηση σωστής σειράς βημάτων
- Μικρό τεστ με τυχαίες δραστηριότητες
- «Τα λάθη μου» με επανάληψη
- Αποθήκευση προόδου στον browser με localStorage

## Πώς ανοίγει

Άνοιξε το αρχείο `index.html` σε browser.

## Πού μπαίνουν οι εικόνες

Οι εικόνες βρίσκονται στον φάκελο:

```text
assets/word/
```

Αυτή τη στιγμή υπάρχουν προσωρινά SVG σχεδιαγράμματα. Μπορούν να αντικατασταθούν από πραγματικά screenshots του Word, αρκεί είτε να κρατήσουν το ίδιο όνομα αρχείου είτε να αλλάξει το αντίστοιχο path στο αρχείο:

```text
data/word-content.js
```

## Πώς αλλάζουν οι ερωτήσεις

Οι δραστηριότητες βρίσκονται στο:

```text
data/word-content.js
```

Υποστηρίζονται προς το παρόν τρεις τύποι:

- `hotspot`: ο μαθητής πατάει στο σωστό σημείο μιας εικόνας
- `choice`: ερώτηση πολλαπλής επιλογής
- `order`: βάζει βήματα στη σωστή σειρά

## Σημείωση για hotspot εικόνες

Για κάθε hotspot χρησιμοποιούνται συντεταγμένες πάνω στην εικόνα:

```js
correctArea: { x: 210, y: 177, width: 42, height: 42 }
```

Αν αλλάξει η εικόνα με πραγματικό screenshot, θα χρειαστεί να ρυθμίσουμε ξανά τις συντεταγμένες του σωστού σημείου.
